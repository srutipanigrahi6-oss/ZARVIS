ZARVIS PWA v3
================
Files:
- index.html
- manifest.webmanifest
- sw.js
- icon.svg

INSTALL:
1. Host these files from an HTTPS website or a localhost HTTP server.
2. Open the site in Chrome/Edge on Android.
3. Use the browser menu and choose "Add to Home screen" or "Install app".
4. Launch ZARVIS from the home-screen icon.

IMPORTANT:
- The PWA does not contain an external AI API key.
- Voice recognition depends on browser/Android support and the serving environment.
- Do not put a secret API key into index.html.
